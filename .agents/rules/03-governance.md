# Rule 03: Agent Governance & Synthesis

## Collaboration Workflow
1. **Ideation:** Creative Maverick proposes feature concepts or UI enhancements.
2. **Review & Refinement:** Standard Setter audits the proposal for code hygiene, performance impact, and accessibility compliance.
3. **Synthesis & Documentation:** Orchestrator logs the decision in `DECISIONS.md` and provides the consolidated implementation specification.

## Documentation Requirements
- Maintain `DECISIONS.md` to track architectural decision records (ADRs).
- Keep component comments clear and self-documenting.
